Cybersecurity Internship from Elevate lab
Task 1: Local Network Port Scanning and Security Risk Assessment using Nmap and Wireshark.

Objective: To perform basic network reconnaissance by identifying active devices and open ports on a local network and assessing the potential security risks associated with exposed services.

Tools Used:
Nmap – Network scanning and port discovery
Wireshark – Basic network traffic analysis

What I Did:
* Identified the local network range.
* Performed a TCP SYN scan using Nmap.
* Scanned 256 IP addresses and identified 5 active hosts.
* Identified open TCP ports and the services associated with them.
* Researched the potential security risks of the exposed services.
* Recommended appropriate security measures to reduce the identified risks.
* Used Wireshark for basic observation of network traffic and packets capture.

Key Concepts Learned:
* Port scanning
* TCP SYN scanning
* IP ranges and CIDR notation
* Network reconnaissance
* Identifying open ports
* Common network services
* Network service exposure
* Potential security risks from open ports
* Basic network security assessment
